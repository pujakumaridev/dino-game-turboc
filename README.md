Dino Jump Game in Turbo C

About the Project

Dino Jump Game is a simple game developed using C/C++ and Turbo C graphics. Control the dinosaur and jump over cactus obstacles to earn points.

Features

- Dinosaur jumping mechanism
- Moving cactus obstacles
- Collision detection
- Score and high-score system
- Increasing game speed
- High-score saving using a file
- Game Over screen

Controls

- SPACEBAR: Jump over obstacles
- Any key: Exit after Game Over

Technologies Used

- C/C++
- Turbo C
- Graphics.h (BGI graphics library)

How to Run

1. Open DINOGAME.CPP in Turbo C.
2. Check that the BGI graphics path is configured correctly.
3. Compile and run the program.
4. Press SPACEBAR to jump over obstacles.

Project Purpose

This project was created to learn C programming, functions, loops, conditions, file handling, collision detection, and computer graphics.
